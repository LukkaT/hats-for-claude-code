# Examples

| File | What it is |
| --- | --- |
| [`hats.conf`](hats.conf) | A commented settings file for someone with a personal account, an employer and two clients. Yours is at `~/.config/hats/hats.conf` (`hat edit`). |
| [`hats-export.json`](hats-export.json) | What `hat export` writes: profiles, emails and folder rules, never logins. Load it on another computer with `hat import hats-export.json`, then `hat login <name>` for each account. |

All names, emails and folders here are made up.
